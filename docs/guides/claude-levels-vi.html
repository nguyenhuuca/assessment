6 Auto gates

ADR-0025 · thêm một label cùng với autopilot.

⚡ Label Cấp 6

Label thêmGate 1Gate 2
(không có)bạn /approvebạn merge
autopilot:auto-mergebạn /approvetự merge
autopilot:autotự duyệttự merge

✅ Điều kiện tự merge

  • PR đã ready, tức là code review ra approve.
  • Không đụng .github/, .claude/, CLAUDE.md, AGENTS.md, scripts/claude-*, migration Liquibase hay .env.
  • ≤ 400 dòng thay đổi ngoài test và docs.
  • Script tự chạy lại mvn verify / test + lint + build webapp.
🔎 Details

Gate 1: plan job chỉ ghi dấu <!-- autopilot:plan-review=approve --> khi plan review ra approve; workflow thấy dấu đó thì tự chạy build job (workflow_dispatch). /revise luôn chờ bạn.

Gate 2: scripts/claude-autopilot-merge.sh (luôn chạy bản trên main) merge squash bằng secret AUTOPILOT_MERGE_TOKEN. Thiếu điều kiện nào thì script comment lý do và để PR cho bạn.

📌 Ví dụ thật

📦
Issue #36 → PR #37 merged + deployed trong ~5 phút, build job $0.39, không ai bấm gì.

⚠️ Rủi ro

Code lên prod mà không ai đọc. Smoke test sau deploy vẫn chạy tay. Rollback = git revert commit squash.
